# Netra

**See beyond the surface.**

Netra is a privacy and security companion app built with Swift and SwiftUI. It helps users understand their digital privacy by monitoring password security, website trackers, privacy activity, and potential security risks.

## Features

* 🔐 Password security monitoring
* 👁️ Website tracker detection
* 🛡️ Privacy and security scoring
* 🚨 Security alerts and recommendations
* 🌐 Safari Web Extension for tracker scanning
* 🔑 Secure credential storage using Keychain

## Tech Stack

* Swift
* SwiftUI
* SwiftData
* Keychain
* Safari Web Extensions
* JavaScript
* App Groups

## Project Status

🚧 Currently in development.

Built as a personal project to explore iOS development, privacy engineering, and secure application design.
